# nalumi

Public website for **Nalumi** — an Android chat client for self-hosted LLM
servers (Ollama, LM Studio, vLLM, llama.cpp, LiteLLM, and anything
OpenAI-compatible).

- Live site: <https://wdedotdevs.github.io/nalumi/>
- Privacy policy: <https://wdedotdevs.github.io/nalumi/privacy-policy>

Static HTML/CSS/JS — no build step, no dependencies. Served by GitHub
Pages from the `main` branch. Edit the files, push, and the site rebuilds
itself in about a minute.
